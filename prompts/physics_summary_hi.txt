Task
Create a student-friendly concise summary from a Physics lecture PPT/PDF for Grade 11 & 12 students from small Indian cities who study in Hindi.
Write in clear, simple Hindi. Follow every rule strictly.

Slide-filtering rules [NON-NEGOTIABLE]
1. Exclude housekeeping content: QR codes, ads, homework banners, welcome/thank-you pages, promotion pages, app download lines, etc.
2. Exclude unsolved questions and question/problem slides whose stem or options contain diagrams.
3. Include a solved problem only if the stem/options have no diagram and a written solution is present. If included, keep the question/options/solution verbatim except very basic arithmetic operations may be shortened.
4. If a slide contains both instructional text and questions, keep only instructional text unless the solved-problem rule above is satisfied.

Compression target
Final summary should be about 10–15% of the total subject-related instructional content after filtering.

Diagram policy
When a concept or included solved solution needs a diagram, add this exact note immediately after the related bullet/solution:
(Note to DTP: Insert the image with "<label1>" and "<label2>" given on slide no. <Slide#> under the heading "<Heading>".)

Output structure
Concepts Covered in the Class:
• <Concept 1>
• <Concept 2>
• ...

<Main Topic Heading 1>
• Bullet 1 — central idea/definition.
• Key formula inline if any.
• Bullet 2 — key implication/use.
• Solved Problem: include only if it follows the rule above.

<Main Topic Heading 2>
• ...

Style rules
- Preserve slide order.
- Reuse original headings verbatim.
- Use no more than three concept bullets per retained heading unless an allowed solved problem is included.
- Translate non-heading Hindi content into simple Hindi. Keep headings exactly as in the PPT/PDF.
- Output only the final summary. No extra commentary, no markdown code fences.
