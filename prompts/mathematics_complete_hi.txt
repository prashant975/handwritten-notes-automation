Task
Create complete student-friendly class notes from a Mathematics lecture PPT/PDF for Grade 11 & 12 (and JEE/NEET) students from small Indian cities who study in Hindi.
Write the notes in clear, simple Hindi (Devanagari). Keep all mathematical terms, symbols, and formulas as-is. Follow every rule strictly.

Slide-filtering rules [NON-NEGOTIABLE]
1. Exclude housekeeping content: QR codes, ads, homework banners, welcome/thank-you pages, promotion pages, app download lines, etc.
2. Exclude every question/problem, solved or unsolved. Do not include question stems, options, answers, or step-by-step solutions in complete-notes mode.
3. If a slide contains both instructional text and questions, keep only the instructional text.

What to capture
- Every definition, theorem, property, standard result, and formula shown.
- Standard forms, special cases, and the conditions under which each result applies.
- State formulas and results; do not reproduce worked-out problem solutions.

Formula rules
- Write formulas in plain text: use "_" for subscripts and "^" for superscripts (e.g. a_n, x^2, nCr, x_1), and write symbols directly (√ × ÷ ≤ ≥ ≠ ± ∞ Σ ∫ π θ). Never use LaTeX, $...$, code fences, or markdown emphasis (* or **) inside a formula.

Language & terminology
- Keep mathematical terms, symbols, variable names, and formulas exactly as they appear; write the surrounding explanation in easy Hindi.

Diagram policy
When a concept needs a diagram/graph from a slide, add this exact note immediately after the related bullet:
(Note to DTP: Insert the image with "<label1>" and "<label2>" from slide <Slide#> under the heading "<Heading>".)

Output structure
Concepts Covered in the Class:
• <Concept 1>
• <Concept 2>
• ...

<Main Topic Heading 1>
• Bullet 1, including the key formula inline if needed.
• Bullet 2 — property / standard result / special case.

<Main Topic Heading 2>
• ...

Style rules
- Preserve slide order.
- Reuse each slide's original heading text verbatim for main headings.
- Keep bullets short, clear, and precise; embed formulas inline in the relevant bullet.
- Output only the final notes. No extra commentary, no markdown code fences.
